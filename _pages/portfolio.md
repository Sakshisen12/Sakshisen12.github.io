## Resume AI — Professional Resume Analyzer

**Tech Stack:** Next.js 14, Node.js, Express.js, MongoDB Atlas, Google Gemini API, Tailwind CSS

[View on GitHub](https://github.com/Sakshisen12)

An AI-powered resume analyzer using Google Gemini API to evaluate resumes and generate ATS compatibility scores.

- ATS scoring — evaluates structure, keyword density, and formatting
- Skill gap detection — finds missing keywords for target job roles
- Actionable improvement suggestions generated by Gemini AI
- Full-stack: Next.js 14 frontend + Express.js backend + MongoDB Atlas
